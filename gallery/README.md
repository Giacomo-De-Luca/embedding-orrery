# Gallery assets

This folder contains static PNG screenshots and figures used to illustrate the
embedding application, its analysis views and steering features. It has no
runtime classes or structured datasets.

- `EMNLP.png` and `emnlp_density.png`: EMNLP embedding figures.
- `emnlp_density_transparent.png`: original-resolution, black-to-alpha derivative
  of `emnlp_density.png`; see
  [conversion and verification](../documentation/GALLERY_TRANSPARENCY.md).
- `concreteness_*.png`, `Lacan1.png`, `dimensionality.png` and `geometry_ui.png`:
  analysis figures and interface screenshots.
- `sae_*.png`: SAE visualization examples.
- `steered_chat.png` and `poetry_steering.png`: steering examples.
- `pipeline_2.png`: pipeline figure.

The documentation site serves its own assets from `docs/public/gallery/`.
Adding a variant here does not change the image displayed by the site.
